    Getting Started

    Stockroom Inventory keeps track of what is on your shelves - items, quantities, prices and suppliers. This manual walks you through everyday jobs and explains every window.

    Before you begin

    • A Windows 10 or Windows 11 PC with Stockroom Inventory installed.
    • The user name and password your administrator gave you.

    Starting the application

    Open the Start menu and click Stockroom Inventory. The Sign in window appears.

    Signing in

    Type your User name and Password, then click Sign in.

    A quick tour

    The main window has three tabs. Items lists everything in stock, Suppliers lists who you buy from and Reports sums up your stock. Use the File, Items and Help menus at the top for everything else.

    Sign in

    Open Stockroom Inventory with your user name and password.

    1. 1

      In User name, type your user name.

      Screen: Sign in

    2. 2

      In Password, type your password.

      Screen: Sign in

    3. 3

      Click Sign in. The main window opens.

      Screen: Items tab

    Screens used: Sign in, Items tab

    Add a new item

    Start tracking something new in the stockroom.

    1. 1

      On the Items tab, click New item.

      Screen: Items tab

    2. 2

      Type a unique SKU.

      Screen: New item window

    3. 3

      Type the item Name.

      Screen: New item window

    4. 4

      Type the Quantity you have.

      Screen: New item window

    5. 5

      Type the Unit price.

      Screen: New item window

    6. 6

      Type the shelf Location.

      Screen: New item window

    7. 7

      Click Save. The item appears in the list.

      Screen: Items tab

    Screens used: Items tab, New item window

    Record a delivery

    Add newly delivered stock to an item's quantity.

    1. 1

      On the Items tab, click the item that was delivered.

      Screen: Items tab

    2. 2

      Click Receive stock.

      Screen: Items tab

    3. 3

      In Quantity received, type how many arrived.

      Screen: Receive stock window

    4. 4

      Click Add to stock. The new quantity shows in the list.

      Screen: Items tab

    Screens used: Items tab, Receive stock window

    Change an item's details

    Correct a price, name or location.

    1. 1

      Click the item in the list.

      Screen: Items tab

    2. 2

      Click Edit.

      Screen: Items tab

    3. 3

      Change the details, for example the Unit price.

      Screen: New item window

    4. 4

      Click Save.

      Screen: Items tab

    Screens used: Items tab, New item window

    Find an item

    Quickly find an item by name or SKU.

    1. 1

      On the Items tab, type part of the name or SKU in Search. The list shows only matching items.

      Screen: Items tab

    Screens used: Items tab

    See what needs reordering

    Find items that are running low.

    1. 1

      Click the Reports tab. Items that need reordering are listed under Low stock.

      Screen: Reports tab

    Screens used: Reports tab

    Change the low-stock level

    Decide at what quantity an item counts as low.

    1. 1

      Click the File menu.

      Screen: Items tab

    2. 2

      Click Settings....

      Screen: Items tab

    3. 3

      In Low-stock threshold, type the new level.

      Screen: Settings window

    4. 4

      Click OK.

      Screen: Items tab

    Screens used: Items tab, Settings window

    Add a category

    Create a new category to group items.

    1. 1

      Click the Items menu.

      Screen: Items tab

    2. 2

      Click Categories....

      Screen: Items tab

    3. 3

      In New category, type the name.

      Screen: Categories window

    4. 4

      Click Add. The category appears in the list.

      Screen: Categories window

    5. 5

      Click Close.

      Screen: Items tab

    Screens used: Items tab, Categories window

    1. 1

    Delete an item

    Remove an item you no longer stock.

    1. 1

      Click the item in the list.

      Screen: Items tab

    2. 2

      Click Delete, then click Yes to confirm. This cannot be undone.

    Troubleshooting

    MessageWhy it happensHow to fix it
    Invalid user name or password.

    The user name or password is wrong.

    Check both and that Caps Lock is off. Ask your administrator to reset your password if needed.

    SKU is required.

    The SKU box is empty.

    Type a stock code, for example HW-1003.

    Another item already uses this SKU.

    SKUs must be unique.

    Use a different SKU, or edit the existing item instead.

    Name is required.

    The name box is empty.

    Type a name.

    Quantity cannot be negative.

    The quantity is below zero.

    Type 0 or more.

    Quantity must be a whole number.

    The quantity has letters or decimals.

    Type a whole number such as 12.

    Unit price must be greater than 0.

    The price is empty or zero.

    Type a price such as 4.50.

    Select an item in the list first.

    You clicked Edit, Receive stock or Delete without choosing an item.

    Click an item in the list first.

    That category already exists.

    A category with the same name is already in the list.

    Choose a different name.

    Low-stock threshold must be between 0 and 1000.

    The number is outside the allowed range.

    Type a whole number from 0 to 1000.
